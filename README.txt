PC 바탕화면에 중요한 디데이를 표시하는 앱입니다.


■ 처음 실행하기
--------------------------------------------------
1. compile.bat 을 더블클릭합니다. (처음 1번만)
   → 같은 폴더에 D-Day_App.exe 가 만들어집니다.
2. D-Day_App.exe 를 실행합니다.

※ Windows 10 / 11 에 기본으로 들어 있는 .NET Framework 로
  빌드되므로 따로 설치할 것은 없습니다.

※ "Windows의 PC 보호" 파란 경고창이 뜨면
  [추가 정보] → [실행] 을 누르면 됩니다.
  개인이 만든 프로그램이라 코드 서명이 없어서 나오는 경고입니다.


■ 사용법
--------------------------------------------------
  ↺   새로고침
  ✎   일정 편집 (추가 · 수정 · 삭제 · 색상)
  ⚙   설정 (색상, 다크/라이트 모드, 투명도, 자동 시작 등)
  ×   종료

  · 위젯을 드래그하면 위치를 옮길 수 있습니다.
  · 오른쪽 아래 모서리를 드래그하면 크기가 바뀝니다. (70~200%)
  · 마우스 오른쪽 클릭으로 메뉴를 열 수 있습니다.
  · 편집 창의 색 점: 클릭 = 다음 색, 우클릭 = 이전 색,
    빈 원 = 테마 색을 따름


■ 일정 파일 (events.txt)
--------------------------------------------------
✎ 편집 창을 쓰면 되지만, 메모장으로 직접 고쳐도 됩니다.
한 줄에 하나씩, 색상은 생략 가능합니다.

  새해=2027-01-01
  프로젝트 마감=2026-12-15|red

색상: red, orange, yellow, green, blue, indigo, violet


■ 새 버전으로 업데이트하기
--------------------------------------------------
새 폴더에 기존 폴더의 events.txt, settings.txt, position.txt 를
옮긴 뒤 새 D-Day_App.exe 를 실행하면 일정과 설정이 그대로 유지됩니다.


■ 지우는 방법
--------------------------------------------------
1. 설정(⚙)에서 [자동 시작]을 끕니다.
   (켜 두었다면 Windows 시작 프로그램에 등록되어 있습니다)
2. 위젯을 종료하고 폴더를 통째로 삭제하면 끝입니다.
